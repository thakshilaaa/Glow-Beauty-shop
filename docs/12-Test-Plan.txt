1. OBJECTIVE

   Verify that the website prototype meets the agreed scope
   and works correctly on desktop, tablet and mobile.

2. SCOPE OF TESTING

   In scope
     - Navigation links
     - Product catalogue content
     - Category filter
     - Contact section
     - Responsive layout
     - Basic accessibility (alt text, keyboard focus)
     - Page load without errors

   Out of scope
     - Payment flows (not implemented)
     - User accounts (not implemented)
     - Server-side performance
     - Load and stress testing

3. TEST ENVIRONMENT

   Browsers   : Chrome, Edge, Firefox
   Devices    : Desktop 1920x1080, Tablet 768x1024, Mobile 375x812
   Hosting    : Local file and GitHub Pages
   Tools      : Browser DevTools responsive mode

4. TEST CASES

   TC ID   Description                                         Category
   TC-01   Homepage loads without errors                       Functional
   TC-02   Navigation links scroll to correct sections         Functional
   TC-03   Product catalogue displays 5 or more products       Functional
   TC-04   Each product has name, description, price           Functional
   TC-05   Category filter shows only matching products        Functional
   TC-06   All filter shows all products                       Functional
   TC-07   Contact section shows contact fields                Functional
   TC-08   No broken internal links                            Functional
   TC-09   Images or placeholders render                       Functional
   TC-10   Layout adapts on mobile 375px                       Responsive
   TC-11   Layout adapts on tablet 768px                       Responsive
   TC-12   Layout works on desktop 1920px                      Responsive
   TC-13   Buttons clickable and tappable on mobile            Usability
   TC-14   Text is readable with good contrast                 Usability
   TC-15   Alt text present on content images                  Accessibility
   TC-16   Keyboard navigation works                           Accessibility
   TC-17   No console errors in browser                        Functional

5. ENTRY AND EXIT CRITERIA

   Entry
     - Homepage, catalogue, about and contact ready
     - Filter working locally
     - All assets committed to Git

   Exit
     - All Must test cases pass, or failures documented
     - Critical defects fixed
     - Test report completed

6. DELIVERABLES

   - This test plan
   - Test report (docs/13-Test-Report.txt)
   - List of defects and their status
