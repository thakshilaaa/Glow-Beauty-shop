1. PROJECT SUMMARY

   A responsive website prototype for a beauty and cosmetics
   shop was planned, designed, developed, tested and deployed
   over four weeks using an Agile-inspired approach. The
   project also produced a complete set of project management
   documents and an automated test script, all maintained in
   a GitHub repository.

2. OBJECTIVES ACHIEVED

   All ten project objectives were achieved within the planned
   four-week timeline:
     - Business requirements understood
     - Stakeholders identified
     - Requirements gathered and documented
     - Scope and objectives defined
     - Four-week schedule developed
     - Risks identified and managed
     - Responsive prototype designed and developed
     - Progress monitored against schedule
     - Testing and quality evaluation conducted
     - Documentation and final evaluation completed

11. LESSONS LEARNED

   See docs/15-Lessons-Learned.txt for the full reflection.

       report.
